# Getting Started

> 🚧 English documentation is in progress. Please refer to the [Chinese Getting Started](/docs/getting-started) for the complete guide.

## Quick overview

1. Download the desktop app (macOS / Windows) and launch it.
2. Use the built-in **one-click install** to set up OpenClaw.
3. The desktop app generates a **QR code** — scan it with the mobile app to pair.
4. Start chatting. Everything runs locally on your machine.

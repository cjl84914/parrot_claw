# Getting Started

> Three steps to get going with ParrotClaw: download and install → connect OpenClaw → pair on mobile.

## Step 1: Download and install the client

| Platform | Download |
|------|------|
| iOS | [Download on the App Store](https://apps.apple.com/cn/app/%E8%AF%AD%E9%B9%A6%E5%8A%A9%E6%89%8B/id6504085275) |
| Android | [Download the APK (zip archive)](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw-android.zip) |
| macOS | [Download the DMG](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw.dmg) |
| Windows | [Download (zip archive)](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw-windows.zip) |
| Linux | Coming soon |

- Android and Windows ship as **zip archives** — unzip them, then install or run.
- On macOS, if the system says the developer cannot be verified, allow it under "System Settings → Privacy & Security".

## Step 2: Connect OpenClaw (desktop)

![Connecting OpenClaw on desktop](/images/step1.webp)

On desktop, click the **OpenClaw button** and follow the prompts to install and connect a local OpenClaw.

If you already have a remote OpenClaw, you can also click **Configure gateway manually** and connect to it directly (aimed at advanced users).

## Step 3: Pair the gateway (mobile)

<p align="center">
  <img src="/images/step2.webp" width="200" alt="Scanning the pairing code on mobile">
</p>

On mobile, tap **Scan pairing code** and follow the prompts to pair the gateway. Once paired, the mobile app is ready to use.

# 使用案例

> 本文通过真实场景演示 ParrotClaw 的用法，帮助你快速理解它能做什么、怎么用。
> 每个案例都包含：场景描述 → 操作步骤 → 效果 → 进阶技巧。

## 案例一：文字创作 — 从一句话到一篇笔记 {#case-1}

### 场景

你是一个内容创作者（自媒体、产品经理、独立开发者），刚有了一个选题灵感，想快速变成一篇结构完整的文章，并且**自动归档到自己的笔记系统**——比如有道云笔记。

传统流程：打开编辑器 → 构思大纲 → 查资料 → 写正文 → 排版 → 复制粘贴到云笔记。至少半小时起步。

用 ParrotClaw：**说一句话，剩下交给它。**

### 前置准备

保存到有道云笔记需要先安装**有道云笔记 CLI** 并配置 API Key（一次性）：

**1. 安装 CLI**（macOS / Linux 一键安装，无需 Node.js）

```bash
curl -fsSL https://artifact.lx.netease.com/download/youdaonote-cli/install.sh | bash
```

> Windows 用户请到[安装指南](https://note.youdao.com/help-center/cli-install-guide.html)手动下载对应架构压缩包并加入 PATH。

**2. 获取 API Key**

访问 [有道云笔记 MCP 控制台](https://mopen.163.com/#/dashboard) 获取 API Key（账号需先绑定手机号）。

**3. 配置 API Key**

```bash
youdaonote config set apiKey YOUR_API_KEY
```

**4. 验证**

```bash
youdaonote list
```

能列出笔记目录即表示配置成功。

**5. 安装技能**

```bash
openclaw skills install youdaonote
```

> 完整安装说明见 [有道云笔记 CLI 安装指南](https://note.youdao.com/help-center/cli-install-guide.html)。

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 说出你的需求，例如：

   > "帮我写一篇关于'一人公司如何用 AI 数字员工提效'的文章，面向独立开发者，1500 字左右，要有真实感，别太虚"

3. Agent 生成文章后，继续下达归档指令：

   > "把刚才的文章保存到有道云笔记，标题叫《一人公司的 AI 数字员工实践》"

4. 打开有道云笔记，文章已经在里面了 ✅

### 效果

- **写作时间**：从 30 分钟+ 缩短到 3 分钟
- **成果沉淀**：文章直接进入你的笔记库，可搜索、可复用、可二次编辑
- **随时续写**：后续想改稿，直接说"把《一人公司的 AI 数字员工实践》改一下第二段"即可

### 进阶技巧

- **批量产出**：一次性让 Agent 生成 5 个选题的初稿，分条保存到不同笔记
- **风格约束**：告诉 Agent 你的固定风格，如"结尾要加行动号召"、"多用短句"
- **发布联动**：写好的文章可以直接让 Agent 发布到掘金（草稿模式），审阅后再公开，详见[案例二](#case-2)

## 案例二：文章发布到掘金 {#case-2}

### 场景

文章写好了，不想再复制粘贴到掘金编辑器里排版。掘金平台支持 Markdown，但手动操作仍然繁琐：打开编辑器 → 新建文章 → 粘贴 → 传封面图 → 设置标签……

用 ParrotClaw：**一句话发布，默认存草稿，审阅后再公开。**

### 前置准备

需要在 OpenClaw 端安装掘金技能（一次性）：

```bash
openclaw skills install juejin-skills
```

安装后首次使用时，AI 会自动打开浏览器跳转掘金登录页，**扫码登录一次**，Cookie 自动保存到本地，之后无需重复登录。

> 详细配置见 [OpenClaw 配置指南 - Skills](openclaw-setup.md#skills技能配置)。

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 直接说：

   > "把 workspace 里的 文章.md 发布到掘金"

3. Agent 自动完成：读取文章 → 打开浏览器 → 登录（首次）→ 上传内容 → **保存为草稿**
4. 你打开掘金后台确认效果，没问题再点公开发布 ✅

### 常用指令

| 指令 | 效果 |
|------|------|
| "把 workspace 里的 xxx.md 发布到掘金" | 发布指定文件为草稿 |
| "查一下掘金的热门文章" | 浏览掘金热门内容，找灵感/参考 |
| "下载这篇掘金文章：https://juejin.cn/post/xxx" | 把别人的文章下载保存为 Markdown，用于学习参考 |

### 进阶技巧

- **写作 + 发布一条龙**：先让 Agent 写文章并保存到本地，再让它发布到掘金，全程对话完成
- **多平台扩展**：同样的思路可以扩展到其他支持 Skills 的平台（博客、公众号等）

## 案例三：音视频处理（ffmpeg） {#case-3}

### 场景

你有一段视频要转成 GIF、一个音频要转换格式、或者想从视频里提取一段片段——这些都是内容创作的日常操作。过去要装剪辑软件或记一堆 ffmpeg 命令，现在直接对话让 Agent 处理。

ParrotClaw 的音视频处理能力由 OpenClaw 内置的 **ffmpeg** 提供，支持：

| 能力 | 说明 |
|------|------|
| 格式转换 | 视频/音频互转（mp4、mov、gif、mp3、wav 等） |
| 视频转 GIF | 提取视频片段转成动图，做演示/表情包 |
| 提取音频 | 从视频中抽出音轨（mp3 / wav） |
| 视频裁剪/拼接 | 截取片段、合并多个视频 |
| 音频处理 | 转码、调采样率、单声道/立体声转换 |

### 前置准备

音视频处理依赖 **ffmpeg**，需要在 OpenClaw 所在机器上安装（一次性）：

**macOS（推荐满血版，含语音识别/字幕/高级编码）：**

```bash
brew tap homebrew-ffmpeg/ffmpeg
brew install ffmpeg-full
```

**Linux（Ubuntu / Debian）：**

```bash
sudo apt update && sudo apt install ffmpeg
```

> 注意：apt 官方源的 ffmpeg 特性不全，建议使用 johnvansickle 的静态编译包，详见 [OpenClaw 配置指南 - Plugins](openclaw-setup.md#plugins插件配置)。

安装完成后可验证：

```bash
ffmpeg -version
```

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 点击 **+** → **文件**，发送要处理的音视频文件
3. 直接说你的需求：

   > "把这段视频转成 GIF，取前 5 秒"
   >
   > "把这个视频的音频提取出来，转成 mp3"
   >
   > "把这段录音转成 44100Hz 单声道 wav"

4. Agent 调用 ffmpeg 处理后，把结果文件发回聊天，点击即可预览/保存 ✅

### 进阶技巧

- **批量处理**：一次发送多个文件，让 Agent 批量转码
- **Live2D 音频格式**：数字人需要 44100Hz / 16-bit / 单声道 PCM WAV，可直接让 Agent 用 ffmpeg 转码后用于数字人朗读
- **视频生成**：配合 ComfyUI 视频工作流，可以对话生成视频，详见 [ComfyUI 使用指南](comfyui-usage.md)

## 案例四：文生图 / 图生图 — 一句话出图 {#case-4}

### 场景

你需要一张产品宣传图、一张封面、一张插画，但不会用 PS，也不想找设计师。

用 ParrotClaw：**描述画面，AI 直接出图。** 有参考图还能做图生图，在参考图基础上改风格、改内容。

### 前置准备

图片生成由 **ComfyUI** 驱动，需要先在 OpenClaw 所在机器上安装 ComfyUI 并准备图像模型（一次性）：

- **安装 ComfyUI** — 克隆仓库、装 PyTorch、启动服务
- **准备模型** — Flux 文生图模型（及图生图所需模型）
- **配置 OpenClaw 集成** — 在 `openclaw.json` 中配置 ComfyUI 工作流

> 详细安装与配置步骤见 [ComfyUI 使用指南 - 安装](comfyui-usage.md#安装-comfyui) 和 [模型准备](comfyui-usage.md#模型准备)。

### 操作步骤

**方式 A：文生图（从零生成）**

1. 打开 ParrotClaw App，进入对话界面
2. 描述你想要的画面：

   > "帮我画一只橘猫坐在窗台上，数字艺术风格"

3. Agent 调用本地 ComfyUI 生成图片
4. 图片直接显示在聊天中，点击可放大查看 ✅

**方式 B：图生图（基于参考图）**

1. 点击 **+** → **相册/拍照**，发送一张参考图
2. 提出修改要求：

   > "把这个人加上胡子，背景改成窗户"

3. Agent 以参考图为基础生成新图，保留原图构图和风格，按你的描述修改 ✅

### 能力说明

| 项 | 说明 |
|------|------|
| 引擎 | ComfyUI（本地运行，不出内网） |
| 模式 | 文生图 / 图生图 |
| 硬件要求 | 建议 16GB 显存（带 ComfyUI 的设备） |
| 使用方式 | `image_generate` + `model="comfy/workflow"`，传 prompt（+ 参考图） |

### 进阶技巧

- **迭代调优**：效果不理想就继续对话调整 prompt（"更写实一点"、"换个配色"），直到满意
- **批量出图**：一次描述多张变体，挑选最合适的
- **创作流水线**：生图 → [音视频处理](#case-3) 转格式/尺寸 → 直接用于文章配图、海报、视频封面

## 案例五：文生曲 — 用文字创作歌曲 {#case-5}

### 场景

你需要一首背景音乐、一段 demo 歌曲或一个 jingle，但不会作曲。过去要找编曲、买版权、或用复杂的 DAW 软件。

用 ParrotClaw：**用文字描述风格，AI 直接生成一首歌。**

### 前置准备

音乐生成由 **ComfyUI + AceStep 模型**驱动，需要先完成以下准备（一次性）：

- **安装 ComfyUI** — 克隆仓库、装 PyTorch、启动服务
- **准备 AceStep 模型** — 文生曲所需的 T2A 模型文件
- **配置 OpenClaw 集成** — 在 `openclaw.json` 中配置音乐工作流

> 详细安装与配置步骤见 [ComfyUI 使用指南 - 安装](comfyui-usage.md#安装-comfyui) 和 [模型准备 - 音乐生成](comfyui-usage.md#2-音乐生成acestep-t2a)。

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 描述你想要的音乐风格：

   > "帮我生成一首歌，摇滚风格，类似 Beyond 的感觉，电吉他主导，节奏明快"

3. Agent 调用 ComfyUI 的 AceStep 文生曲工作流生成歌曲
4. 生成完成后，音频直接发回聊天，点击即可播放/保存 ✅

### 能力说明

| 项 | 说明 |
|------|------|
| 模型 | AceStep（Text to Audio Song） |
| 输入 | 风格描述（流派、乐器、氛围、参考风格） |
| 输出 | MP3 音频 |
| 示例风格 | "Rock, Beyond style, electric guitar..." |

### 当前限制

- **歌词需要预先配置**：歌词（lyrics）写在 ComfyUI 工作流文件中，目前需要通过对话外的配置修改，暂不支持在对话中动态传入新歌词。想换歌词时，需要编辑工作流 JSON 文件。

### 进阶技巧

- **风格描述越具体越好**：流派 + 参考乐队 + 乐器 + 节奏，生成结果更接近预期
- **组合使用**：生成的歌曲可以配合 [音视频处理](#case-3) 转格式、裁剪，用于视频配乐、播客片头等

## 案例六：会议记录 — 录音进去，纪要出来 {#case-6}

> 🧪 该案例基于功能设计撰写，完整效果待作者实测后更新。

### 场景

你开完一场 1 小时的会议，手机里有一段录音，或者你正在会议现场。过去你要：

1. 自己回听录音（1 小时）
2. 手动整理要点（30 分钟）
3. 写成纪要发给同事（15 分钟）

用 ParrotClaw：**说一句"开始会议记录"，剩下的交给它**——录音、转文字、整理纪要、归档，全自动。

### 前置准备

归档到飞书云文档需要启用飞书插件（一次性）：

```bash
openclaw plugins install npm:@openclaw/feishu
```

安装后在 OpenClaw 配置中填入飞书应用的 **App ID / App Secret**，启用插件后即可对话创建飞书云文档。

> 详细配置见 [OpenClaw 配置指南 - Plugins](openclaw-setup.md#plugins插件配置)。

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 说：

   > "开始会议记录"

3. Agent 开始录音，正常开会即可
4. 会议结束，说：

   > "结束会议，整理成纪要"

5. Agent 自动完成：语音转文字 → 结构化整理 → 输出纪要 ✅
6. 需要归档时再说：

   > "把会议纪要保存到飞书云文档，标题《XX 项目周会纪要 - 8月10日》"

7. 飞书里就能看到这份纪要，可直接分享给参会同事 ✅

### 纪要长什么样

Agent 输出的结构化纪要示例：

```markdown
# XX 项目周会纪要（2026-08-10）

## 参会人
Alex、小林、王工

## 讨论主题
1. ParrotClaw 1.0 上线数据回顾
2. 使用场景文档优先级确认

## 关键结论
- App Store 已上线，官网和 Gitee 开源同步完成
- 场景落地优先于国际化，先跑通"写作 + 会议记录"闭环

## 待办事项
| 事项 | 负责人 | 截止时间 |
|------|--------|----------|
| 补充使用案例文档 | Alex | 本周 |
| 验证飞书文档分享流程 | Alex | 本周 |

## 下次会议
8月17日 10:00
```

### 效果

- **整理时间**：从 1.5 小时缩短到 5 分钟
- **不遗漏**：AI 回听不会走神，细节都在
- **自动归档**：纪要直接进飞书/知识库，沉淀成公司资产

### 进阶技巧

- **模板化**：提前告诉 Agent 你喜欢的纪要格式，之后每次会议都按模板输出
- **知识库联动**：纪要归档到知识库后，以后直接问"上次会议定的待办是什么"，AI 帮你检索
- **多段录音**：一天多场会，逐段发送，Agent 能区分不同会议生成多份纪要

## 案例七：代码解读 — 把陌生项目讲给你听 {#case-7}

### 场景

你拿到一个陌生项目要上手、接手同事留下的代码、或者想回顾自己半年前写的逻辑。传统流程：翻目录 → 逐个看文件 → 跑起来试 → 查文档，几小时起步，还容易漏掉关键点。

用 ParrotClaw：**一句"读一下这个项目"，剩下的交给它。**

### 前置准备

🟢 **零配置**。代码解读是 OpenClaw 的天然能力，App 连上 OpenClaw 就能用，不需要安装任何插件、模型或工具链。

> 说明：AI 读取的是 **OpenClaw 所在机器上的文件**。私有化部署下，你的代码只在自己的机器/内网里被读取分析，**不出内网**——对代码敏感的团队尤其友好。

### 操作步骤

1. 打开 ParrotClaw App，进入对话界面
2. 直接告诉它项目路径：

   > "读一下 /Users/xxx/my_project，讲讲这个项目的架构"

3. Agent 分析后输出：技术栈、目录结构、核心模块、入口与关键逻辑
4. 继续追问，深入细节：

   > "user_service.dart 里那个 login 函数具体怎么工作的？"
   >
   > "这个项目有没有明显的 bug 或安全隐患？"

5. 也可以不填路径，直接点击 **+** → **文件**，把代码文件发给它读 ✅

### 效果

- **理解速度**：陌生项目从小时级缩短到分钟级
- **零门槛**：不用装任何工具，开箱即用
- **多用途**：接手旧项目、代码审查、学习开源项目，都能直接问

### 进阶技巧

- **解读沉淀成文档**：让 AI 把架构说明整理成笔记保存到有道云，随时可查（联动[案例一](#case-1)）
- **代码审查**：让 AI 检查性能问题、安全隐患、潜在 bug，当你的免费 Code Review
- **画架构图**：让 AI 把模块关系画成图，一图看懂项目全貌
- **对比分析**：让 AI 对比两个相似项目/两个版本的差异，快速定位改动

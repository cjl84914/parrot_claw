# ParrotClaw 隐私政策

> 更新日期：2026 年 7 月 9 日
> 生效日期：2026 年 7 月 9 日

---

## 1. 关于本政策

ParrotClaw（语鹦助手）是一款开源的 AI 数字员工应用（以下简称"本应用"或"我们"），由 Alex 开发并维护。本应用采用 **MIT 协议** 发布，源代码托管于 Gitee 平台。

本隐私政策旨在帮助您了解使用 ParrotClaw 时，您的信息如何被收集、使用和存储。

**关键承诺：ParrotClaw 是一款私有化部署的应用，没有云端服务器，不收集您的个人信息。**

---

## 2. 我们收集的信息

### 2.1 我们不收集的信息

ParrotClaw 是**无账号系统**的应用。您不需要注册、登录或提供任何个人信息即可使用。我们**不收集**：

- 姓名、手机号、邮箱地址等个人身份信息
- 账号密码或登录凭证
- 设备标识符（IMEI、IDFA、MAC 地址等）
- 位置信息
- 通讯录或社交关系
- 使用行为画像

### 2.2 应用本地处理的信息

以下信息仅在您的设备本地处理，**不会上传到我们的任何服务器**（因为我们根本没有服务器）：

| 数据类型 | 处理方式 | 是否上传 |
|----------|----------|----------|
| 聊天记录 | 存储在设备本地（Hive 数据库） | ❌ 不上传 |
| 服务器配置 | 存储在设备本地，包括您配置的 OpenClaw 服务地址和 Token | ❌ 不上传 |
| 语音输入 | 通过 sherpa-onnx 在设备本地离线识别，不会发送到云端 | ❌ 不上传 |
| 图片/文件选送 | 选送内容直接发送到您自己配置的 OpenClaw 服务器 | ❌ 不经过我们 |
| 应用偏好设置 | 存储在设备本地（SharedPreferences） | ❌ 不上传 |


## 3. 信息的存储与处理

### 3.1 本地存储

- **聊天记录**：使用 Hive 数据库存储在您的设备应用私有目录中
- **服务器配置**：使用 Hive 数据库存储在设备本地
- **语音模型文件**：SenseVoice ASR 模型（约 237MB）和 Silero VAD 模型存储在应用资源目录，首次运行自动拷贝到应用支持目录

您可以在应用的「设置 → 数据管理」中清除所有本地存储的数据。

### 3.2 您自行配置的服务器

ParrotClaw 需要连接您自行部署的 OpenClaw 服务器才能运行。当您使用应用时：

- 您的消息、语音识别结果、选择的文件会通过 **WebSocket 连接** 发送到您配置的服务器地址
- 这些服务器由您完全掌控（可以部署在局域网、Tailscale 虚拟网络或您自己的公网服务器）
- 数据处理行为由您配置的 OpenClaw 服务器和 Skills 决定
- 我们无法访问这些服务器上的任何数据

### 3.3 第三方云服务

ParrotClaw 可以选择性地与以下第三方服务交互，**所有这些服务均由您自行配置和掌握**：

- **Microsoft Edge TTS**（edge-tts）：如果您使用 edge-tts 作为 TTS 方案，音频合成请求将发送到微软的在线服务。这部分不在我们的控制范围内，请参阅微软的隐私政策
- **HuggingFace**：ASR 模型文件从 HuggingFace 下载，仅首次使用需要，下载完成后不再与 HuggingFace 交互

## 4. 权限说明

ParrotClaw 需要以下系统权限才能完整运行：

| 权限 | 用途 | 说明 |
|------|------|------|
| **麦克风** | 语音识别输入 | 离线 ASR 识别需要。仅在您按住录音按钮时激活，不持续监听 |
| **相册/相机** | 发送图片 | 您手动选择或拍摄图片发送时使用 |
| **文件存储** | 文件选择与保存 | 选择文件发送，以及保存生成的图片/音频到设备 |
| **网络** | 连接您的 OpenClaw 服务器 | App 本身不连接任何第三方网络服务 |
| **本地网络** | 局域网内发现服务 | macOS 上用于连接局域网内的 OpenClaw 服务 |

所有权限仅在您主动操作时使用，不会在后台偷偷开启。您可以在系统设置中随时开启或关闭这些权限。

---

## 5. 数据安全

### 5.1 传输安全

- 您与 OpenClaw 服务器之间的 WebSocket 连接可以使用 **Token 认证** 加密
- 通过 Tailscale 或 HTTPS 代理（如 Ngrok）的连接会自动加密
- 我们建议在生产环境中使用 Tailscale Serve 或 HTTPS 代理确保传输安全

### 5.2 本地安全

- 本地存储的聊天记录和服务器 Token 存储在设备私有目录，其他应用无法访问
- 建议为您的设备设置锁屏密码/生物识别，保护本地数据安全

### macOS 额外说明

macOS 构建的应用在 Release 模式下**未启用沙盒**（sandbox），因此具有：

- 读写用户选择的文件、下载目录
- 执行外部命令（用于调用 ffmpeg、edge-tts 等工具）
- 访问 Homebrew 安装目录（`/opt/homebrew`）
- 进程执行与 fork 权限

这些权限是运行 TTS Wrapper 等脚本的必要条件，不会用于访问未授权的数据。

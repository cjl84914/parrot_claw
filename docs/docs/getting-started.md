> 如何安装并运行 ParrotClaw App。

---

## 前置要求

- Flutter 3.x+
- Dart 3.x+
- OpenClaw（后端服务）

## 安装

```bash
# 克隆项目
git clone https://gitee.com/alexcai/parrot_claw.git
cd parrot_claw

# 安装依赖
flutter pub get

# 运行
flutter run
```

## 配置 OpenClaw

1. 安装并运行 OpenClaw
2. 在 ParrotClaw 中配置 OpenClaw 的 WebSocket 地址
3. 开始对话！

详细配置请参考 [OpenClaw 配置指南](/docs/openclaw-setup)。

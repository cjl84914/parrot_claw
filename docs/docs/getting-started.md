# 快速开始

> 三步上手 ParrotClaw：下载安装 → 连接 OpenClaw → 移动端配对。

## 第一步：下载和安装客户端

| 平台 | 下载 |
|------|------|
| iOS | [App Store 下载](https://apps.apple.com/cn/app/%E8%AF%AD%E9%B9%A6%E5%8A%A9%E6%89%8B/id6504085275) |
| Android | [下载 APK（zip 压缩包）](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw-android.zip) |
| macOS | [下载 DMG](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw.dmg) |
| Windows | [下载（zip 压缩包）](https://parrot-1251065087.cos.ap-guangzhou.myqcloud.com/release/parrotClaw-windows.zip) |
| Linux | 即将上线 |

- Android / Windows 下载的是 **zip 压缩包**，解压后安装/运行。
- macOS 若提示无法验证开发者，请在「系统设置 → 隐私与安全性」中允许打开。

## 第二步：连接 OpenClaw（桌面端）

![桌面端连接 OpenClaw](/images/step1.webp)

在桌面端点击 **OpenClaw 按钮**，根据提示安装并连接本地 OpenClaw。

如果已有远程 OpenClaw，也可以点击**手动配置网关**，直接连接远程 OpenClaw（适合专业人士）。

## 第三步：配对网关（移动端）

<p align="center">
  <img src="/images/step2.webp" width="200" alt="移动端扫描二维码配对">
</p>

在移动端点击**扫描二维码**，根据提示配对网关。配对成功后，移动端即可直接使用。
